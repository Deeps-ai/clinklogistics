# C Link Logistics & Shipping Pvt Ltd

This project is the official website for C Link Logistics & Shipping Pvt Ltd — a global freight forwarding company specializing in NVOCC, forwarding and destination logistics for Afghanistan and CIS regions.

## Tech Stack
- React + TypeScript
- Vite
- TanStack Router
- Supabase
- Tailwind CSS
- shadcn/ui

## Development

npm install
npm run dev
